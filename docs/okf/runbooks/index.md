# Runbooks

* [Build and preview](build-and-preview.md) - Build the static bundle, serve it, and see the real icons.
* [Capture the screens](capture-the-screens.md) - Build the app at one commit, then screenshot a route list and the dialogs behind clicks, with every backend write answered in the browser.
* [Deploy to Vercel](deploy-vercel.md) - A merge to main deploys production, staging mirrors main as the one public preview on the dev Clerk instance, and the environment is set per target on the project.
* [Run locally](run-locally.md) - Install, copy the example environment, start the dev server against a local or the staging backend.
